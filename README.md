# 🏛️ 역사팡 식민통치와 저항~6.25전쟁

초등 5학년 2학기 사회 교과와 연계한 역사 학습 게임입니다. 정리 노트의 빈칸을 채우고 확인문제를 풀며 역사를 배우고, 마지막에는 배운 내용으로 카드배틀을 합니다.

| 단계 | 이름 | 다루는 내용 |
| :---: | :--- | :--- |
| 1 | 빼앗긴 나라와 저항 | 을사늑약, 헤이그 특사, 의병 운동, 조선 총독부, 국외 독립운동, 토지 조사 사업 |
| 2 | 3·1 운동과 독립을 향한 노력 | 3·1 운동, 대한민국 임시 정부, 한인 애국단, 실력 키우기 운동, 학생 운동, 봉오동·청산리 |
| 3 | 일제 통치 시기의 생활 | 철도와 쌀 수탈, 둘로 나뉜 도시, 민족정신 말살 정책, 신채호, 한국광복군 |
| 4 | 광복과 6·25 전쟁 | 광복과 달라진 생활, 대한민국 정부 수립, 6·25 전쟁, 피란민의 삶, 전쟁이 남긴 상처 |
| 5 | 역사 카드배틀 | 보스 3연전 |

PC·크롬북·태블릿(가로 화면)에 맞춰 만들었습니다.

## 실행

```bash
npm install
npm run dev
```

배포용 빌드는 `npm run build`, 실행은 `npm run start`입니다.

## 이미지 출처

- 유물·유적 사진: 국립중앙박물관, 국가유산청 국가유산포털 (공공누리 제1유형, 출처표시). 게임 화면에 사진마다 출처를 표시했습니다.
- 캐릭터·보스·배경·랜딩 그림: 생성형 AI 도구로 제작한 창작 그림입니다.
